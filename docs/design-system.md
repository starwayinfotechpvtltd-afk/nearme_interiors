# Design System: Near Me Interiors

## Theme Preset: Premium Blue + White

## Colors
- **Primary:** `#0A2540` (Deep Indigo / Midnight Navy) - represents depth, stability, trust.
- **Secondary:** `#1E5EFF` (Vibrant Electric Blue) - accentuates growth, energy, action.
- **Accent:** `#3B82F6` (Royal Blue) - used for focus states, highlights, micro-elements.
- **Background:** `#F8FBFF` (Sleek Clean Slate White) - provides high-contrast, clean modern editorial feel.
- **Cards:** `#FFFFFF` (Pure White with subtle border/shadow) - creates layers of depth.
- **Text Primary:** `#0F172A` (Slate 900) - optimal readability.
- **Muted Text:** `#64748B` (Slate 500) - secondary explanations.

## Glassmorphism Settings
- Backdrop Blur: `backdrop-blur-xl`
- Background: `bg-white/10` or `bg-white/70` for light glass
- Border: `border-white/20`
- Shadow: `shadow-2xl`
