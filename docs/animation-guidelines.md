# Animation Guidelines: Near Me Interiors

## Philosophy
Animations must elevate, not distract. They must feel fluid, premium, and performant.

## Standard Settings
- **Ease Curves:** `[0.16, 1, 0.3, 1]` (Ultra-premium easeOutExpo).
- **Parallax Factor:** Light offsets on portfolio showcase cards.
- **Scroll Triggers:** Lazy-loading container elements on scroll using Framer Motion's `whileInView`.
