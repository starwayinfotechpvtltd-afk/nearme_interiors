# Components Library: Near Me Interiors

## Key Reusable Components
1. **Glass Card:** Combined backdrop-blur, subtle borders, and soft shadows.
2. **Magnetic CTA Button:** Framer-motion-driven interactive button.
3. **Animated Counter:** Uses `react-countup` to animate performance metrics.
4. **Logos Marquee:** Endless smooth scrolling partner marquee.
5. **Exit Intent Popup:** Triggered to offer the free growth guide.
6. **WhatsApp Float:** Bottom right floating conversion widget.
