- `/` - Flagship Homepage
- `/seo-for-interior-designers` - Dedicated SEO Landing Page
- `/google-ads-for-interior-designers` - Dedicated Google Ads Landing Page
- `/meta-ads-for-interior-designers` - Dedicated Meta Ads Landing Page
- `/social-media-marketing-for-interior-designers` - Social Media Page
- `/website-design-for-interior-designers` - Web Design Page
- `/local-seo-for-interior-designers` - Local Search Page
- `/blog` - Editorial & Case Studies Feed
- `/blog/[slug]` - Dynamic Articles & In-depth Studies
- `/location/[city]` - City-specific SEO Lander (Mumbai, Delhi, Pune, Bangalore, Kolkata, Chennai, Hyderabad, Ahmedabad)
